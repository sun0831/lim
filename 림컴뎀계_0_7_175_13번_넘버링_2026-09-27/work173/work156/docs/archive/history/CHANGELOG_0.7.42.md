# 0.7.42 — 동적 진동 소모/이전 효과 다중 처리

## 실제 인격 원문 기준으로 추가 처리
- 대상의 진동을 최대 N 소모 → 소모한 진동 × 배수만큼 자신의 진동 횟수 증가
- 자신의 진동 횟수를 최대 N 소모 → 소모한 진동 횟수만큼 대상의 진동 횟수 증가
- 자신의 진동 횟수를 전부 소모 → 소모한 값만큼 대상의 진동 횟수 증가

## 원칙
- 진동 위력과 진동 횟수를 분리 유지
- 실제 원문에 있는 소모/이전만 파싱
- 임의의 일반 진동 소모 규칙으로 확대하지 않음
