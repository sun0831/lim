# 0.7.106 — 충전 위력 괄호형 다음 턴 신속 오판 수정

## 확인된 문제
실제 원문 형식:
`턴 종료 시, (자신의 충전 위력 / 2)만큼 다음 턴에 신속 얻음 (최대 2, 소수점 버림)`

기존 passive compiler의 `충전 N당 다음 턴 신속` 정규식은 `자신의 충전 횟수/위력 N당` 형태만 인식했다.
따라서 괄호형 `/ N` 표현이 매칭되지 않고 해당 규칙이 누락되어, 실제 실행 경로에서는 다음 턴 신속이 예약되지 않을 수 있었다.

## 수정
- `(자신의 충전 위력 / N)만큼 다음 턴에 신속 ... (최대 C)` 형태 추가 인식.
- `FloorValue`를 유지하여 소수점 버림 의미 보존.
- `AddNextTurnStatus`로 예약하여 현재 턴에 즉시 신속을 부여하지 않음.
- 기존 `충전 N당` 스케일링 규칙과 별도 경계로 처리.
