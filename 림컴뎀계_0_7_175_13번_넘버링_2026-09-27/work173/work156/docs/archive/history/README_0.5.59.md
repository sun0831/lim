# 림컴뎀계 0.5.59

## 이번 버전
### 누적 자원 소모 → 자원 획득
실제 전투 중 누적된 자원 소모량을 별도로 추적하도록 보강했다.

대표적인 명시형 문구:
- `전투 중 누적으로 자신의 충전 횟수 10을 소모할 때마다, 충전 1 얻음`

처리 방식:
- 현재 충전량과 누적 소모량을 별도로 관리
- 10 단위 등 임계값을 실제 소모 시점에 판정
- 한 번의 큰 소모가 여러 임계값을 넘으면 각 임계값마다 변환
- 획득한 충전은 즉시 이후 코인/스킬 계산에 반영
- 일반 `resources` 계열 자원도 동일한 누적 소모 카운터를 사용
- 애매한 자연어 문구는 자동 실행하지 않음
