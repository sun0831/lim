# 0.7.76 — 실제 원문 조건 누락 오판 수정

## 발견
실제 원문 `identity-10101 / 정보중화`:

`정신력이 가장 낮은 아군 1명 이번 턴에 정신력이 감소한 경우 턴 종료 시 정신력 10 회복`

기존 컴파일 결과는 대상 선택(`sp_min`)은 올바르게 잡았지만 `이번 턴에 정신력이 감소한 경우` 조건을 `Always`로 남겼다.

따라서 최저 정신력 아군이 이번 턴에 정신력이 감소하지 않았어도 턴 종료 회복이 발동할 수 있었다.

## 수정
- `LowestAllySPDecreasedThisTurnCondition` 추가
- 현재 최저 SP 생존 아군을 기준으로 이번 턴 실제 SP 감소 이벤트 존재 여부 검사
- SP 변경 이벤트에 `identity_id` 기록
- 해당 원문 조건을 위 Condition으로 컴파일

## 원칙
- 단순 기능 추가가 아니라 실제 원문과 기존 계산 해석의 불일치 수정
- `정신력이 가장 낮은 아군` 대상 선택과 `이번 턴 정신력 감소` 조건을 분리 유지
