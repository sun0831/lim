# 림컴뎀계 0.5.62

## 변경 사항

### 인격 코인 재사용 고점 보정 확정
현재 계산기 범위에서는 E.G.O를 제외하고, 인격의 확률형 코인 재사용은 고점 계산을 위해 **조건 충족 시 100% 재사용**으로 처리한다.

- SP/정신력 관련 조건: 조건이 충족되면 재사용 100%
- 디버프/부정적 효과 개수 관련 조건: 조건이 충족되면 재사용 100%
- 기타 인격의 명시적 확률형 재사용: 조건이 충족되면 재사용 100%
- 앞면/뒷면/크리티컬/충전/기타 발동 조건은 제거하지 않고 그대로 판정
- 최대 재사용 횟수는 원문 제한을 유지
- 원래 확률값은 `original_probability`로 보존하여 데이터 추적 가능
- `high_point_assumption=true`로 해당 보정임을 명시

E.G.O 재사용은 현재 계산 범위에서 제외하며, 추후 E.G.O 기대값 계산으로 별도 구현한다.
