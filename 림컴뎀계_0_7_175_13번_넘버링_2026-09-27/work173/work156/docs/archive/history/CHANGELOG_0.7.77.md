# 0.7.77 — 실제 원문 조건 누락 오판 수정

## 확인된 오판
실제 원문 `identity-10108 / 가라앉는 지식`:

- `피격 시 공격자에게 침잠 1 부여`
- `보호막이 있는 동안 피격 시 침잠 1 추가 부여`

기존 컴파일에서는 두 효과가 모두 `Hit + Always`로 컴파일되어, 보호막이 없는 상태에서도 두 번째 추가 침잠이 적용될 수 있었다.

## 수정
`passive_compiler_v29.py`의 조건 파서에 다음 원문 경계를 추가:

- `보호막이 있는 동안 피격 시 ...` → `HasStatus('Shield', 'self')`

즉, 추가 침잠 효과는 패시브 소유자의 현재 보호막 보유 여부를 확인한 뒤에만 적용된다.
