# 림컴뎀계 0.5.101

0.5.100의 처치 기반 충전 분배 구현을 기반으로 새벽 사무소 교차 연계와 재사용 코인 화상 추가 피해를 보강한 버전.

### 핵심 변경
1. 새벽 사무소 S1 신규 흐트러짐 연계의 발동 대상을 새벽 사무소 인격으로 제한.
2. `연계` / `여명의 섬광` 교차 연계의 지정 스킬 조건 유지.
3. 재사용 코인 적중 시 화상 위력 기반 분노 피해 구현.
4. 코인당 최대 10 / 턴당 최대 20 추가 피해.
5. 싱클레어 전장 조건 적용.
6. 재사용 코인 인덱스를 공통 코인 실행 경로에 전달하고 로그에 기록.
