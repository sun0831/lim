# 림컴뎀계 0.5.99 — Ally Target / Ally Rank Conditions

## 구현
- 아군 대상 선택을 FighterState 기반으로 일반화
  - 속도 최고/최저
  - 현재 체력 비율 최고/최저
  - 최대 체력 최고/최저
  - 충전 최고/최저
  - 탄환 최고/최저
  - 정신력 최고/최저
  - 호흡 횟수 최저
- `자신을 제외하고` / `자신과` 형태의 대상 범위 처리
- 다중 아군 대상 선택 및 사망 아군 제외
- 아군 편성 순서를 이용한 결정적 tie-break
- 현재 행동 인격이 아군 중 최고/최저 순위인지 판정하는 `AllyRankCondition` 추가
  - 속도
  - 체력 비율
  - 최대 체력
  - 정신력
  - 충전
  - 탄환
- 기존 `자신 vs 대상 속도` 조건과 `가장 빠른/느린 아군` 조건 충돌 방지

## 보수적 처리
- 소속/가문/특정 인격 조건이 섞인 대상 선택은 자동 추론하지 않음
- `가장 빠른 아군이 공격할 때`처럼 '행동 주체 조건'과 실제 '대상 지정'을 분리
- 지원되지 않는 효과/트리거는 기존처럼 원문을 남기고 실행하지 않음
