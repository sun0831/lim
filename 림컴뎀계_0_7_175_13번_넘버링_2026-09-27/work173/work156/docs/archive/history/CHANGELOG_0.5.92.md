# 림컴뎀계 0.5.92 — multi-target shared coin state

## 변경 사항
- 다중 대상 공격에서 **논리적 코인 1개를 대상 수만큼 다시 던지는 것처럼 처리하지 않도록** 코인 해석 구조를 정밀화.
- 코인별 공격자 전역 상태를 논리적 코인당 1회만 처리:
  - 공격자 Bleed 코인 발동/자해
  - 코인 자원 소모
  - 탄환 소모
  - Poise Count 소비
- 대상별 처리는 계속 독립적으로 수행:
  - 실제 피해
  - 대상 HP
  - 대상 상태/흐트러짐
  - 코인 적중 후 대상 측 효과
- 마지막 탄환 계열처럼 **코인 종료 시 대상별 추가 피해**가 필요한 특수 효과가 각 대상에 적용될 수 있도록 동일한 논리 코인의 탄환 전후 상태를 전달.
- 코인별 다중 대상 지정(`coin_target_ids`의 리스트 값)에서도 동일한 공유 상태 원칙 적용.
- 이미 죽은 대상은 해당 코인 해석에서 건너뛰고 `coin_target_skipped` 로그를 남김.
- 다중 대상 코인 처리 로그에 `secondary_target` 및 코인 번호를 명시.
