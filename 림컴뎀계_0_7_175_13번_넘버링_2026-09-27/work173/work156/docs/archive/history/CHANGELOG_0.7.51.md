# 0.7.51 — 공격 종료 부정 효과 부여 후 정신력 회복 공통화

## 반영
- 실제 인격 원문에서 반복되는
  `공격 적중 시 해당 공격 스킬로 부정적인 효과를 부여했으면, 공격 종료 시 자신의 정신력 N 회복 (턴당 M회)`
  패턴을 공통 `attack_end_negative_status_sp_gain` Rule로 일반화.
- 현재 확인된 실제 적용 대상:
  - `identity-10215` 거미집 약지 제자: 정신력 +4, 턴당 2회
  - `identity-10614` 거미집 약지 아비: 정신력 +4, 턴당 3회
- 단순히 공격 피해가 발생한 것만으로는 발동하지 않으며, 해당 공격에서 실제 부정 효과가 새롭게 증가했는지를 `negative_status_applied` 이벤트 플래그로 판정.
- 이미 존재하는 부정 효과에 이번 공격이 추가 위력/횟수를 부여한 경우도 증가분을 감지하여 발동.
- 정신력 회복으로 최대 정신력에 새롭게 도달하고 원문에 후속 조건이 있는 경우, 다음 턴 `참격 피해량 증가 1`을 예약.
- 후속 효과는 `sp_gain` 공통 Effect로 Rule IR 경계를 통과하도록 추가.

## 검증
- 관련/회귀 테스트: **131 passed / 0 failed**
- 실제 10215/10614 catalog compilation 확인 포함.

## 주의
- `부정적인 효과`는 현재 엔진의 명시된 부정 상태 집합을 기준으로 판정한다.
- 상태를 제거했다가 같은 공격에서 다시 부여하는 등 현재 엔진이 직접 표현하지 않는 복합 상태 변환은 추측하지 않는다.
