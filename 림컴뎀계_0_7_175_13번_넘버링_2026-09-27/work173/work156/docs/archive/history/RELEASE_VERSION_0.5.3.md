# 림컴뎀계 0.5.3

## 목적
사용자가 직접 지정한 덱/스킬/행동 순서와 초기 예열·적 상태를 그대로 1턴 순차 시뮬레이션한다.

## 0.5.3 핵심 변경
- 스킬 원문 데이터의 고빈도 조건부 코인 위력 패턴 확대
  - 호흡/충전/상태이상 스택 기반
  - 상태이상 합 기반
  - 속도 차이 기반
  - 대상 상태 임계값 기반
- 스킬 원문에서 `[사용시]` 자원 소모/정신력 감소를 구조화
- 스킬 전체 `파괴 불가 코인` 표기 지원
- 스킬 전체/조건부 최종 위력 데이터 연결
- 코인별 `피해량의 N% 흐트러짐 손상` 구조화 및 전투 상태 반영
- 대상의 부정적 효과 개수 기반 조건부 피해 증가 구조화
- 원호 공격은 사용자가 선택한 덱에 실제 원호 대상이 존재할 때만 생성
- 기존 184 인격/카탈로그 자동 로딩 유지
- 기존 회귀 테스트 8개 통과

## 주의
지원하지 않는 특수 기믹을 임의의 데미지 공식으로 추정하지 않는다. 원문은 계속 `source_effects`/parse report에 보존한다.
