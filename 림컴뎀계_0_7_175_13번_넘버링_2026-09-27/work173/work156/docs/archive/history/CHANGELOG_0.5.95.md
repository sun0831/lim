# 림컴뎀계 0.5.95 — target-role coins & target-local death bridge

## 변경
- 코인별 명시적 대상 역할을 데이터 모델에 추가: `single_main`, `sub`.
- 스킬 원문에서 다음 고신뢰 문구를 자동 파싱:
  - `N코인 이 코인에는 메인 타겟만 피해`
  - `N코인 이 코인은 1명의 대상에게만 적중함 (메인 타겟 우선...)`
  - `N코인 이 코인에는 서브 타겟만 피해`
- 사용자 입력 `coin_target_ids`가 존재하면 카탈로그 대상 역할보다 항상 우선.
- 다중 대상 공격에서 코인별 대상 역할을 독립적으로 적용.
- 적중 후 고정 피해/상태 효과로 대상이 사망하는 경우도 대상 사망 이벤트로 기록.
- 동일한 EnemyState의 사망 이벤트는 한 번만 통지.
- 다중 대상에서 대상별 사망 콜백을 수집하고, 생성된 후속 액션은 전체 원본 액션 종료 후 큐에 삽입하도록 연결.
- 기존 공격자 측 효과 1회/논리 코인 구조 유지.
