# 0.7.33 — E35 337 기준 원인 해소: 거미집의 검 료슈 화상 부여 보정

## 실제 인격 원문
- `identity_catalog_v2.json`
- 인격: `identity-10415` 거미집의 검 료슈
- 패시브: `재회 [再會]`
- 실제 문구: `중지 제자 이스마엘 : 방어 레벨 2 증가, 기본 스킬로 부여하는 화상 위력 +1`
- 해당 이스마엘 인격: `identity-10814` 거미집 중지 제자 이스마엘

## 구현
- 위 문구를 일반적인 `화상 피해량 +1`로 처리하지 않음.
- `identity-10814`가 사망 상태일 때만 활성화되는 조건을 추가.
- 기본 공격 스킬(S1/S2/S3)에서만 활성화되는 조건을 추가.
- 효과를 현재 CoinHit 이벤트의 Context modifier로 처리:
  - 방어 레벨 +2
  - 기본 스킬이 부여하는 Burn Potency +1
- Burn도 Tremor와 동일하게 공통 keyword mutation boundary에서 application modifier를 적용하도록 확장.
- 다른 인격의 일반적인 Burn 규칙으로 확대하지 않음.
