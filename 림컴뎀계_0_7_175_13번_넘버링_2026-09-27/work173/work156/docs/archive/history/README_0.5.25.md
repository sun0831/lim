# 림컴뎀계 0.5.25

## 출혈 확률 합 계산을 1턴 Solver에 연결

이번 버전부터 각 행동에 `bleed_clash_probability`를 넣으면 확률 합 런타임이 실제 1턴 Solver 실행 중 동작한다.

### 동작
- 각 합의 현재 적 활성 코인을 출혈 발동량으로 사용
- 승/무/패 분기 후 다음 합의 코인 상태 재계산
- 최대 99합
- 99번째 합은 강제 적 승리
- 최종 분포에서 하위 5%와 상위 5% 확률 질량을 제거하고 중앙 90% 기대값 사용
- `expected_bleed_procs_raw`와 `expected_bleed_procs`를 모두 기록
- 계산된 기대 출혈 발동량을 이후 행동의 가상 출혈 Count(`virtual_bleed_count`)에 반영
- 기존 정수형 실제 상태와 분리하여 기대값 계산에서 소수 기대값을 유지
- `bleed_count_infinite`가 켜져 있으면 Count 소모를 하지 않음

### 확률 입력
`bleed_clash_probability.outcome_probabilities`로 합별 W/T/L 확률을 직접 지정할 수 있다.

지정하지 않으면 현재 아군/적 SP와 양쪽 활성 코인의 앞면/뒷면 위력을 이용해 확률을 계산한다.

### 주의
이 버전의 확률 합 모드는 **전체 전투를 확률 분기해서 모든 후속 데미지까지 완전한 기대값으로 재계산하는 전체 상태공간 시뮬레이션은 아직 아니다.**
현재는 확률 합 → 기대 출혈 발동량 → 이후 행동의 가상 출혈 Count 연결까지 구현했다. 따라서 실제 합 결과 자체는 기존 Solver의 입력/해결 방식을 유지한다.
