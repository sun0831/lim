# 0.7.41 — 인격 파일 기준 동적 진동 부여 경계

## 실제 원문 기준
- `identity-10810` 서부 츠바이 협회 3과
  - `1081002 못 지나갑니다.`
    - `3코인 [적중시] (자신의 진동 횟수/2)만큼 진동 부여 (최대 4)`
  - `1081003 수호`
    - `3코인 [적중시] 자신의 진동 횟수를 전부 소모하여, 소모한 값만큼 진동 부여. (최대 20)`
    - 같은 문장의 후속 `초과한 진동 x 5% 피해량 증가`는 이번 단계에서 별도 처리하지 않음.

## 구현
- `(자신의 진동 횟수 / 2)`는 내 진동 Count를 읽어 내림 계산하고 최대 4까지 대상 Tremor Count로 부여.
- `자신의 진동 횟수를 전부 소모하여 ... 진동 부여`는 실제 소모량을 대상 Tremor Count로 전달하고 최대 20 적용.
- 두 효과 모두 기존 Tremor Potency는 임의로 변경하지 않음.
- 두 효과는 실제 원문 패턴에만 연결했으며 일반적인 진동 부여 규칙으로 추론하지 않음.
- 멀티라인 코인 원문을 하나의 코인 clause로 파싱하도록 coin-local parser에 `re.S` 적용.
