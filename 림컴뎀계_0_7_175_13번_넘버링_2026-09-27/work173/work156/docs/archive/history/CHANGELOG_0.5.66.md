# 림컴뎀계 0.5.66

## Captain Ishmael deterministic support command

- `identity-10808` 피쿼드호 선장의 S2 `[사용시]` 원호 공격 명령을 별도 기믹 규칙으로 연결.
- 원문에 있는 `가장 높은 공명의 공명 당 20% 확률`은 프로젝트의 high-roll 설정에 따라 **발동 확률 100%**로 취급.
- 원호 공격 대상은 조작 패널에서 선장 이스마엘의 **우측 아군**으로 결정.
- 우측 아군은 해당 턴의 다음 사용자 지정 행동을 지원 공격으로 즉시 한 번 실행하고, 기존 사용자 지정 행동은 그대로 유지.
- 따라서 우측 아군의 동일 인격이 지원 공격 + 원래 행동으로 2회 행동하는 경우를 허용.
- 우측 아군의 다음 사용자 지정 행동이 없으면 지원 공격을 임의로 생성하지 않고 스킵.
