# 0.7.72 — 실제 원문 오판 전수대조 회차

## 목적
구현율이 아니라 `identity_catalog_v2.json`의 실제 문구와 현재 계산기 내부 의미가 다른 **오판**만 찾는다.

## 이번 회차
실제 원문에서 반복되는 Target/우선순위/상태·자원 축을 재대조했다.

### 재확인된 의미
- 현재 HP 최저/최고 ≠ HP 비율 최저/최고 ≠ 최대 HP 최저/최고
- 정신력 최저/최고는 SP 절대값 기준
- 충전 최저/최고는 충전 횟수 기준
- 탄환 최저/최고는 탄환 수 기준
- 호흡 위력과 호흡 횟수는 별도 축
- bare `호흡을 가장 많이/적게 보유`는 현재 프로젝트의 원문 용례상 호흡 위력 기준
- `호흡이 없거나 호흡 위력이 가장 낮은`은 미보유자를 0으로 포함하는 위력 최저 의미
- 출혈/침잠 등의 `위력 + 횟수의 합`은 두 값을 합산하는 의미
- 편성 순서와 속도는 별도 축
- 상태/소속 필터 후 SP 등의 순위를 매기는 복합 Target은 필터가 먼저 적용되어야 함

## 결과
이번 회차에서 기존 코드가 위 의미를 반대로 해석하는 추가 확정 오판은 발견되지 않았다.

## 주의
원문에 존재하지만 아직 실행 경로가 없는 기믹은 이번 감사의 '오판'으로 집계하지 않았다. 이는 미구현/부분구현 감사와 별도 관리한다.
