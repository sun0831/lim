# 림컴뎀계 0.5.24

## 이번 버전 핵심

### 출혈 기반 확률 합 런타임 추가
`bleed_clash_probability_v1.py`를 추가했다.

- 합마다 현재 적 활성 코인 수만큼 출혈 발동
- 승리(W): 적 일반 코인 -1
- 무승부(T): 양쪽 코인 수 유지
- 패배(L): 아군 코인 -1
- 다음 합에서 변경된 상태로 확률 재계산
- 가능한 경로를 상태 집계 방식으로 계산
- 최대 99합
- 99번째 합은 무조건 적 승리

### 양 극단 5% 제거
확률 경로의 최종 총 출혈 발동 횟수 분포에서
- 하위 5% 확률 질량 제거
- 상위 5% 확률 질량 제거
- 중앙 90%의 가중 평균을 `expected_bleed_procs`로 사용

원본 기대값은 `expected_bleed_procs_raw`로 함께 보존한다.
임의적인 100% 보정이나 추가적인 확률 보정은 사용하지 않는다.

### 합 Runtime 무승부 수정
기존 `ClashExchangeRuntime`의 T 처리에서 양쪽 코인을 감소시키던 동작을 수정해,
무승부에서는 양쪽 코인 수를 그대로 유지하도록 변경했다.
