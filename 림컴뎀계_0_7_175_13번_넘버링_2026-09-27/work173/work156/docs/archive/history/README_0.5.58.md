# 림컴뎀계 0.5.58

## 인격 확률형 코인 재사용 100% 보정

이번 버전은 기존에 파싱만 해두었던 확률형 코인 재사용을 결과에 명시적으로 노출한다.

### 추가
- 인격의 확률형 `코인 재사용`은 고점 계산을 위해 **조건 충족 시 100%**로 보정
- 최대 재사용 횟수는 원문 제한을 그대로 적용
- SP/디버프 등 발동 조건은 실제 전투 상태에서 판정
- `expected_reuse_count` / `reuse_probability`에도 100% 보정값 반영
- E.G.O 재사용 확률은 현재 범위에서 제외하고, 향후 별도 기대값 계산으로 처리

### 계산 원칙
- 결정적 `turn_damage`에서 인격의 확률형 재사용도 조건 충족 시 100% 발동으로 처리한다.
- 앞면/뒷면, SP, 충전, 디버프 등 실제 발동 조건은 제거하지 않는다.
- 최대 재사용 횟수는 그대로 유지한다.
- E.G.O는 나중에 별도의 확률/기대값 계산 경로로 추가한다.

### 범위 메모
현재는 인격의 일반적인 고점 계산을 우선하여 확률 Branch를 사용하지 않는다. 조건이 성립하면 재사용을 확정 실행하므로 재사용된 코인의 피해/HP/상태/자원/Trigger 변화가 기존 실행 경로를 그대로 탄다.
