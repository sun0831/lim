# 림컴뎀계 0.6.3

0.6.1의 교차 인격·자원 트리거 기반 위에 거미집 엄지 아비 로쟈의 **예지안**에서 확정적으로 계산 가능한 수명주기를 연결한 유지보수 릴리스.

## 핵심 변경

- 예지안: 전투 첫 등장 시 예지안 30 획득
- 실제 합이 끝날 때마다 예지안 1 소모
- 마지막 예지안이 소모되면 예지안 과열 상태를 명시적으로 기록
- 합 패배 후 예지 스킬 발동은 예지안이 남아 있을 때만 허용
- Windows 기본 인코딩에 의존하던 카탈로그 테스트를 UTF-8 명시 로드로 수정

## 의도적으로 남긴 항목

- 예지안 과열 후 재장전, 다음 턴 처분 변환, 신(心)-불명예 등은 슬롯/다음 턴/전투당 상태를 추가로 요구하므로 근거 없는 추정 없이 gap으로 유지
- 단말기로 전해진 지령과 신탁 단말기 [카두세우스]의 무작위 무기별 효과는 데이터에 효과 매핑이 없어 gap으로 유지
