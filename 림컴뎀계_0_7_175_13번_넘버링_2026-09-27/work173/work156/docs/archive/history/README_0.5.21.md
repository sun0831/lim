# 림컴뎀계 0.5.21

## 병렬 전투 엔진 보강

0.5.20의 Clash/크리티컬 보강을 유지하면서, 특수자원과 병렬로 상태·피해·추적 계층을 확장했다.

### 1. 상태/피해 이벤트
- Bleed가 공격 코인 투척 시 실제 자가 HP 피해를 적용하고 Count를 소비.
- Sinking의 SP 피해를 -45~45 범위로 제한하고 변화 이벤트를 기록.
- 고정 피해(`damage_fixed`)를 이벤트 로그에 남기고, 피해 후 흐트러짐 임계값을 재검사.
- 코인 부가효과가 흐트러짐 임계값을 넘기는 경우에도 다음 코인이 갱신된 상태를 보도록 재검사.
- 턴 종료 Burn 피해 후에도 흐트러짐/사망을 재검사.

### 2. 방어 레벨 상태
- FighterState에 `defense_level_bonus`를 추가.
- 공격자의 방어 레벨 보정이 전투 상태에 보존되고 결과에도 출력.

### 3. 특수자원 효과 타입 확장
- 구조화 효과에서 `resource`, `resource_gain`, `resource_consume`를 공통 ResourceRuntime으로 전달.
- 기존 충전/탄환/호흡 및 일반 특수자원 시스템과 함께 사용할 수 있는 확장 지점을 마련.

### 4. 결과 추적 강화
각 행동 결과에 다음을 추가:
- 코인별 실제 피해/롤/크리티컬 결과
- 행동 시작 특수자원 스냅샷
- 행동 종료 특수자원 스냅샷
- 행동 시작/종료 SP
- 행동 시작/종료 호흡(포이즈) 상태
- 실행된 코인 이벤트 목록

따라서 `총딜 → 인격 → 스킬 → 행동 → 코인 → 당시 자원/상태` 순으로 추적 가능한 구조가 됐다.
