# 0.7.31 — 진동 인격 파일 기준 진행

## 실제 소스 확인
- `identity_catalog_v2.json`에서 `identity-10406` / `1040603` (`LCCB 대리 료슈` / `대.박`)의 실제 문구 확인:
  - `3코인 [크리티컬 적중 시] 진동, 파열 의 위력과 횟수가 2배로 부여됨`
  - `3코인 [적중시] 진동 4 부여, 진동 횟수 2 증가`
  - `3코인 [적중시] 파열 4 부여, 파열 횟수 2 증가`
  - `3코인 [적중시] 진동 폭발`
- 해당 2배 문구는 현재 인격 파일에서 1건만 확인됨.

## 구현
- `skill_text_parser_v19.py`에서 위의 정확한 인격 스킬 문구를 3코인에만 기록.
- 배수는 현재 코인의 Tremor/Rupture 부여 효과에만 전달.
- `크리티컬 적중`일 때 위력/횟수 각각 ×2.
- 크리티컬이 아니면 기본 부여량 유지.
- 진동 폭발은 별도 효과로 유지하여 기본 Burst의 진동 횟수 소비만 적용.
- compound grant (`진동 4 부여, 진동 횟수 2 증가`)를 위력/횟수 양쪽으로 보존.
- 배수는 상태/전역 옵션으로 저장하지 않으며 다음 이벤트에 잔류하지 않음.

## 되돌린 것
- 0.7.29에서 잘못 일반화했던 `진동/파열 2배` RuleIR/공통 패시브 규칙은 제거.
- 해당 효과를 일반 진동 Runtime 규칙으로 취급하지 않음.
