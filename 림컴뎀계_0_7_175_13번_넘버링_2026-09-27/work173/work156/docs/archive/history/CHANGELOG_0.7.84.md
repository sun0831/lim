# 0.7.84 — 실제 원문 수치 스케일링 오판 추가 정합화

## 목적
기능 추가가 아니라, 실제 identity/skill 원문과 기존 컴파일 결과가 다르게 해석되는 수치 스케일링 오판을 수정.

## 확정 오판

### 1. 상태 수치 `N당 피해량 +X% (최대 Y%)`
기존 generic parser가 `N`과 cap을 보존하지 않고 선형/무제한 modifier로 떨어뜨리는 사례가 있었음.

수정:
- `대상의 화상 3 당 피해량 +10% (최대 50%)`
  → `floor(Burn potency / 3) × 10%`, cap 50%
- `대상의 화상당 피해량 +5% (최대 60%)`
  → `Burn potency × 5%`, cap 60%
- 출혈/파열/침잠/진동도 동일한 source-backed 구조로 처리.
- `진동 위력 N당 피해량`은 기존 전용 handler와 중복 생성하지 않음.

### 2. 상태 스케일링이 고정 피해량 증가로 중복 해석되는 문제
`대상의 화상 3당 피해량 +10%` 같은 문장이 일반 `피해량 +10%` parser에도 걸려 flat +10%가 추가되는 문제를 제거.

### 3. `호흡`과 `호흡 횟수` 필드 오판
기존 `호흡 N당 코인 위력`이 항상 `poise_count`로 평가됨.

수정:
- `호흡 N당` → Poise potency
- `호흡 횟수 N당` → Poise count

### 4. 스케일링 코인 위력의 flat +1 중복
`호흡 5당 코인 위력 +1` 등이 일반 `코인 위력 +1` parser에도 걸려 flat +1이 추가되는 문제를 제거.

## 검증
- 신규/관련 테스트: **118 PASS / 0 FAIL**
- 전체 pytest: **902 PASS / 9 FAIL**
- 기존 9 FAIL은 이번 변경으로 새로 발생한 실패가 아니라 기존 fixture/inventory 문제.

## 주의
이번 작업은 아직 지원되지 않는 복합 코인 위력 수식 전체를 새로 구현한 것이 아님. 이미 parser가 처리하던 수치 스케일링의 **잘못된 해석/중복 해석**만 수정함.
