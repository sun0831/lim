# CHANGELOG 0.7.83

## 목적
실제 인격/스킬 원문과 현재 컴파일된 수치식의 의미가 달라지는 **수치 스케일링 오판** 감사 및 수정.

## 확정 수정
1. `호흡 횟수 5당 코인 위력 +1 (최대 3)`
   - 기존: 최대값을 증가량 그룹으로 잘못 읽어 cap=1
   - 수정: source의 최대 3을 cap으로 사용
2. `대상의 진동 위력 6 당 피해량 +5% (최대 15%)`
   - 기존: `%` 증가량에 divisor 6을 사용
   - 수정: +5%를 사용하고 최대 15%를 cap으로 유지
3. `대상의 파열과 침잠의 합 2당 피해량 +1% (최대 15%)`
   - 기존: +1% 대신 divisor 2를 % 증가량으로 사용
   - 수정: 합/2 × 1%, 최대 15%

## 추가 정합화
- `(충전 위력 / N)만큼 다음 턴 신속 ... (최대 M)` 패턴의 cap 참조를 group 2로 정정.
  현재 catalog에서 확인된 사례는 N=2, M=2로 동일하므로 이번 버전에서 별도 결과 차이를 만드는 실제 사례는 아니지만, 동일 문법의 오독을 방지하도록 수정.
