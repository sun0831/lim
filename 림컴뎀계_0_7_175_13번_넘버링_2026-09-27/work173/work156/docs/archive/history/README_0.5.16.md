# 림컴뎀계 0.5.16

## 이번 버전
특수자원 생명주기의 **스킬 사용시 획득/소모 → 실제 Fighter 자원값 반영 → 이후 행동의 변형 판정** 연결을 강화했다.

### 변경사항
- `[사용시] 새벽불 N 얻음/증가/소모` 같은 인격 고유 자원을 `SkillData.resource_gain/resource_cost`로 변환.
- 자원 변경은 `ResourceRuntime`을 통해 기록되며, 시나리오에서 지정한 최대/최소값과 임계값 이벤트를 사용.
- 기존 `[사용전] 자원 임계값 → 변형 스킬` 판정과 연결되어 같은 턴 앞선 행동에서 자원이 증가하면 이후 사용 시점에 변형 여부가 다시 판정됨.
- 자원 후보명은 별도 `SPECIAL_RESOURCE_NAMES_v1.json`과 코드의 보수적 후보 집합으로 관리한다. 자동 추출 후보 전체를 무조건 실행 규칙으로 승격하지 않는다.
