# 0.7.35 — 인격 파일 기준 진폭 변환 Skill Parser 연결

## 이번 변경

실제 `identity_catalog_v2.json`에서 확인된 진동/진폭 문구를 기준으로, 기존 공통 `AmplitudeRuntime`을 Skill parser 경로에서도 사용하도록 연결했다.

### 추가된 실제 원문 패턴
- `진동 - 작열로 진폭 변환`
- `진동 - 사슬로 진폭 변환`
- `진동 - 과다출혈로 진폭 변환`
- `진동 - 붕괴로 진폭 변환`
- `진동 - 반향으로 진폭 얽힘`
- `진동 - 작열이 없으면, 진동 - 작열로 진폭 변환`
- `대상이 진폭 변환 상태가 아니면, 진동 - 붕괴로 진폭 변환`
- `대상의 진동 위력과 횟수의 합이 20 이상이면, 진동 - 붕괴로 진폭 변환`
- `대상의 속도가 자신보다 낮다면, 진동 - 사슬로 진폭 변환`

## 의미론

- 진폭 변환/얽힘은 공통 `AmplitudeRuntime`을 사용한다.
- 진폭 변환 자체가 Tremor potency/count를 임의로 소비하지 않는다.
- 변환 상태 생성 시 현재 Tremor potency/count를 snapshot으로 기록하는 기존 `AmplitudeRuntime` 동작을 그대로 사용한다.
- `진동 위력 + 횟수` 임계값은 실제 원문에 명시된 경우에만 조건으로 평가한다.
- `진폭 변환 상태가 아니면`은 실제 conversion state 존재 여부로 판단한다.
- 속도 조건은 실제 원문 `대상의 속도가 자신보다 낮다면`에 한정해 처리한다.
