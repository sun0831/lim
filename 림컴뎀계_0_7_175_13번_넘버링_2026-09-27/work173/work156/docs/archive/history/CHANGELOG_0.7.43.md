# 0.7.43 — 인격 파일 기준 진동 적용 보정 + 특수 경계 묶음

## 실제 인격 원문 기반

### identity-10304 N사 중간 망치
- 원문: `못 이 있는 대상에게 부여하는 진동 횟수 +1`
- 대상이 못을 보유한 경우에만 Tremor application Count +1.
- 일반 Tremor Count 증가 규칙으로 일반화하지 않음.
- 기존 event-scoped `tremor_count_bonus` 경계를 재사용.

### identity-10409 20구 유로지비
- 원문: `자신을 제외한 아군의 공격으로 흐트러짐 상태가 된 적을 스킬 1로 공격함. (턴 당 1회)`
- 기존 Action/Support 경계의 `stagger_assist`로 등록.
- 추가 Tremor 획득/마지막 코인 Burst 효과는 생성된 Skill 1 실행 경계에서 별도 검증 대상으로 유지.

## E35 기준값
- 위 10304 규칙의 실제 RuleIR 변환이 새로 추가되어 E35 coverage가 337 → 338로 증가.
- 338 / 1103 = 30.64%.
- 기존 337 기준값을 유지하기 위해 구현을 숨기거나 오탐 처리하지 않음.
