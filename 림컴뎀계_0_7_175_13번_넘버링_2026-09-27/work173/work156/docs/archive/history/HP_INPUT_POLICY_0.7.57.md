# HP 입력 정책 0.7.57

## 목적

1턴 계산기에서는 아군/적군의 HP를 인격/적 데이터에서 자동 추정하지 않고, 전투 시작 상태의 사용자가 직접 지정할 수 있다.

## 입력

모든 전투 유닛은 동일한 필드를 사용한다.

- `hp`: 전투 시작 현재 HP
- `max_hp`: 전투 시작 최대 HP

### 아군

```json
"allies": {
  "identity-id": {
    "hp": 320,
    "max_hp": 500
  }
}
```

### 적군

```json
"enemy": {
  "hp": 1200,
  "max_hp": 2000
}
```

두 값은 독립적인 사용자 입력값이다. 따라서 인격별 HP 성장 계수나 적군별 기본 HP 데이터가 없어도 계산할 수 있다.

## 계산 중 상태

입력값은 `START_STATE`의 canonical HP로 사용한다.

- 피해: `hp` 감소
- 회복: `hp` 증가, `max_hp` 초과 금지
- 최대 HP 변경 효과가 실제 규칙으로 존재할 경우 `max_hp`를 상태 효과로 변경할 수 있음
- 초기 `hp`와 `max_hp`는 인격/적 데이터로 자동 덮어쓰지 않는다.

## 범위

HP 성장 계수/기본 HP 자동 산출 기능은 이번 작업 범위에 포함하지 않는다.
기존 시나리오와의 호환성을 위해 HP 필드가 생략된 경우의 legacy 기본값은 유지한다.
