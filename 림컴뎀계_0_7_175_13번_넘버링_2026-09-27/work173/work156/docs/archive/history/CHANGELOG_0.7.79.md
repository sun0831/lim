# 0.7.79 — 실제원문 보호막 대상 조건 추가 오판 수정

## 감사 목적
실제 인격/스킬 원문과 현재 계산기의 조건 해석이 다른 사례를 찾는 정합성 감사.

## 발견
`보호막이 있으면` 조건이 일부 문장 형태에서 `Always()`로 남아 있었다.

확인된 실제 원문 예:
- identity-11: `자신에게 보호막이 있으면, 화상 1 추가 부여`
- identity-137: `메인 타겟에게 보호막이 있으면, 대신 기본 스킬로 가하는 피해량 +3%`
- identity-180: `대상에게 보호막이 있으면, 피해량 +30%`

기존 구현은 `보호막이 있는 동안 피격 시` 형태만 별도 처리하고, 일반적인 `자신에게/대상에게/메인 타겟에게 보호막이 있으면`은 Shield가 FighterState의 별도 수치 필드라는 이유로 조건을 보존하지 못했다.

## 수정
- `HasShield` Condition 추가.
- `self`, `enemy` 대상의 현재 `shield > 0`을 직접 검사.
- `자신에게 보호막이 있으면`
- `대상에게 보호막이 있으면`
- `메인 타겟에게 보호막이 있으면`
- `보호막이 있는 동안 피격 시`
  를 모두 동일한 Shield 조건으로 정합화.

`Shield`를 일반 status-map 항목으로 취급하지 않고 `FighterState.shield`를 기준으로 판정한다.

## 검증
- 보호막 원문 조건 신규/기존 감사 + 관련 회귀: 118 PASS / 0 FAIL
- 전체 회귀는 기존 8개 fixture/inventory 실패를 별도로 유지하며, 이번 변경으로 신규 실패가 발생하지 않는지 확인한다.
