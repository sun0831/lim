# 0.7.86 — 실제원문 `N당` 정수 나눗셈 오판 수정

## 감사 목적
이미 구현되어 있던 수치 스케일링이 실제 원문의 `N당` 의미와 다르게 계산되는지 대조.

## 확정 오판
기존 `BinaryValue('/')`는 일반 실수 나눗셈을 수행했는데, 원문의 `N당` 스케일링은 해당 단위가 몇 번 완성되는지를 의미하므로 정수 버림이 필요했다. 컴파일러 주석은 이미 `floor`를 전제로 하고 있었지만 실제 Runtime 값 트리에는 `FloorValue`가 누락되어 있었다.

예: `대상의 화상 3당 피해량 +10%`
- 기존: 화상 4 → 13.333...%
- 수정: 화상 4 → 10%

## 수정 범위
- 상태 N당 피해량
- Tremor 전용 N당 피해량
- named resource N당 피해량
- Poise N당 코인 위력
- 상태/자원 N당 크리티컬 피해량
- 잃은 체력 N당 피해량
- 잃은 체력 N%당 피해량
- 자신+대상 잃은 체력 합 N%당 피해량
- 초과 체력/호흡 등 명시적 N당 스케일링
- 명시적으로 `소수점 버림`인 Charge Power / N → 다음 턴 Haste

## 검증
- 0.7.8x 감사/관련 테스트: 29 PASS / 0 FAIL
- 이번 수정은 기능 추가가 아니라 기존 수치 스케일링의 원문 정합성 수정.
