# 0.7.38 — 진동 특수 경계 실행 연결

## 이번 변경
- 실제 인격 파일의 `추가된 코인` 규칙을 별도 `added_coin_rules`로 보존.
- 조건/원본 코인/파괴 불가 여부를 분리해 저장.
- 추가 코인은 원본 코인의 효과를 복제하되 `is_added_coin` 실행 Context를 별도로 전달.
- `추가된 코인 적중 시` 효과가 원본 코인에 잘못 적용되지 않도록 경계 분리.
- 실제 원문에 명시된 `진동 폭발 + 진동 횟수 1 감소`를 추가 코인에만 부착.
- 10414의 `고독 부여 시 대신 진동 폭발`은 실제 고독 부여 지점에서 대체하도록 실행 연결.
- 일반 `진동 폭발`에는 Count 감소를 자동 부여하지 않음.

## 검증
- 특수 경계 신규 테스트: 3/3
- Tremor / Amplitude / RuleIR 관련 테스트: 67/67
- 11216 추가 코인 직접 실행 경로에서 4번째 코인 및 명시적 Count 감소 확인.
- 10414 고독 대체 경계에서 기존 고독 유지 + 진동 폭발 확인.

## 주의
- `solve()` 결과의 표시용 coin trace는 기존 3개 요청 코인 기준으로 유지되는 부분이 있어, 추가 코인 자체를 UI trace에 완전히 노출하는 것은 별도 trace-contract 작업으로 남겨둠.
- 상태 결과에는 추가 코인 실행 결과가 반영됨.
