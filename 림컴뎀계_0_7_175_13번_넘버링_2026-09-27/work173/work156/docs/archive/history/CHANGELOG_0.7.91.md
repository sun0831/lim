# 0.7.91 — 다음 턴 스케일링 원문 오판 수정

## 목적
실제 인격 원문과 passive compiler의 다음 턴 수치 효과 해석을 대조하여, `N당` 스케일링이 고정값으로 축약되거나 현재 턴 효과로 잘못 들어가는 문제를 수정했다.

## 수정
- `자신의 호흡 N당 다음 턴에 신속 X (최대 C)`
  - `floor(poise_potency / N) * X`, cap C
  - NEXT_TURN_STATE의 Haste로 예약
- `자신의 충전 횟수 N당 다음 턴에 신속 X (최대 C)`
  - `floor(charge / N) * X`, cap C
- `자신의 화상 N당 다음 턴에 공격 레벨 증가 X (최대 C)`
  - `floor(burn_potency / N) * X`, cap C
  - 기존 즉시 `attack_level_bonus` 중복 생성 방지
- `충전 횟수 ... 당 다음 턴 신속` 문법에서 `1을 얻음` 형태도 인식

## 원문 감사 확인
현재 catalog에서 확인된 해당 패턴:
- 호흡: 5건
- 충전: 2건
- 화상: 1건

모두 `AddNextTurnStatus` 기반 스케일링으로 컴파일되는 것을 확인.

## 테스트
- 신규 감사 테스트: 3건
- 관련 회귀 묶음: **114 PASS / 0 FAIL**
- 전체 회귀: 이번 배치에서는 완료하지 못함(장시간 테스트 타임아웃 이력 유지).

## 주의
이번 변경은 누락 기능 추가가 아니라, 이미 존재하던 다음 턴 효과의 `N당` 수치 의미와 적용 시점을 실제 원문에 맞게 보존하는 정합성 수정이다.
