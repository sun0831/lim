# 림컴뎀계 0.5.101

## 새벽 사무소 교차 원호공격 보강
- 새벽 사무소의 `기본 스킬 공격 종료 → 신규 흐트러짐` 연계가 실제 새벽 사무소 인격만 트리거하도록 제한.
- 자기 자신을 제외한 새벽 사무소 인격의 S1이 신규 흐트러짐을 만들었을 때 연계 트리거가 동작하도록 조건 강화.
- 기존 그레고르/싱클레어 지정 스킬(`새벽을 가르는 검`, `새벽녘`, `낙인`, `타오르는 일격` 등)의 교차 연계는 지정된 스킬명 조건을 유지.

## 재사용 코인 → 화상 기반 추가 피해
- 새벽 사무소 파우스트/그레고르의 `재사용 코인 적중 시 대상 적의 화상 위력만큼 분노 피해` 계열 효과를 일반 트리거로 구현.
- 재사용 코인에서만 발동하며, 일반 코인에는 발동하지 않음.
- 코인당 추가 피해 상한 10, 턴당 누적 상한 20을 적용.
- 싱클레어가 전장에 있어야 발동.
- 추가 피해를 별도 이벤트 로그로 기록.
