# 림컴뎀계 0.6.9

0.6.9는 `멀티크랙 사무소 대표`의 처치 후 충전 분배 우선순위를 보강한 패치입니다.

### 핵심
- 처치 후 충전 분배에서 현재 충전량만 보지 않고, 해당 아군이 충전을 소모하거나 직접 획득하는 스킬을 보유하는지 확인합니다.
- 원문에 명시된 "충전을 소모하거나 스스로 획득하는 스킬을 보유한 아군에게 우선" 조건을 런타임 대상 선택에 반영합니다.
- 해당 조건이 같으면 현재 충전량이 낮은 아군, 그 다음 편성 순서를 사용합니다.
- 기존 `Requested → Resolved → Triggered`, Action `state_diff` 추적 구조와 호환됩니다.

### 검증
- 전체 테스트 통과: 251개
- 신규 처치 후 충전 분배 우선순위 회귀 테스트 추가.
