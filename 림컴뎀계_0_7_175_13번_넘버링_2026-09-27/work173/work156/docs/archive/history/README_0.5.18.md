# 림컴뎀계 0.5.18

## 이번 버전 핵심
- 특수자원 조건을 코인 위력 조건까지 일반화
- `자신의 X가 N 이상/이하이면 코인 위력 +M` 패턴 지원
- 특수자원 조건은 코인/행동 시점의 최신 상태를 읽음
- 선언된 `turn_reset` 자원을 모든 전투원에 적용하는 공통 API 추가
- 턴 시작 트리거로 생성되는 추가 행동을 실제 ActionQueue에 삽입
- 턴 시작 추가 행동은 사용자 요청 행동의 `requested_index`를 변경하지 않음
- 변형 스킬이 `전부 소모`를 명시하면 변형 직후 해당 자원을 소비

## 정확성 원칙
자동 추출 후보는 검증되지 않은 상태로 남기며, 자연어가 불명확한 규칙은 자동 추측하지 않는다.
