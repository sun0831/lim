# 림컴뎀계 0.6.1

## 고영향 교차/지원 기믹 보강

### 구현
- LCCB 대리 돛대
  - 탄환 최저 보유 아군의 탄환 소모 스킬 사용 시 호흡 3 획득
  - 턴당 1회
  - 기존 마지막 탄환 소모 코인 피해 50% 추가 피해 연계 유지
- 거미집 약지 제자/아비
  - 전투 시작 시 전장 약지 소속 인격 수 × 2의 생체 재료 횟수 획득
  - 최대 10
  - 스킬 종료 시 실제 피해 발생 → 생체 재료 횟수 +5
  - 대상 사망 시 추가 +3
- 흑운회 와카슈 — 흑운도
  - 아군 피격 피해 발생 → 공격자에게 S1 일방 공격
  - 해당 아군 사망 또는 HP 25% 미만 → S4 '뒷골목의 규칙' 일방 공격
  - 아군 대상별 1회
  - S4 계열 효과는 턴당 최대 2회
  - 저HP/사망 조건에서는 S1 중복 발동 방지

### 런타임 개선
- TriggerRule에 `turn_cap` 보조 예산 추가
- `after_skill`에 실제 행동 피해량/탄환 소모/최저 탄환 인격 컨텍스트 전달
- battle-start lifecycle 이벤트 실행 추가
- affiliation 기반 동적 자원 초기화 효과 추가
- 호흡 증가 효과를 실제 FighterState에 반영
