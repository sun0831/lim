# 림컴뎀계 0.5.53

## 이번 버전
### 1. 확률형 코인 재사용 데이터 구조화
실제 인격 데이터에서 확인되는
- `40% 확률로 코인 재사용`
- `부정적인 효과 1개당 재사용 확률 +20%`
- `스킬당 최대 2회 재사용`
형태를 자동 파싱해 `reuse_rules`에 보존한다.

확률은 deterministic 실행에 임의로 100% 적용하지 않는다. 별도 `reuse_probability_runtime_v1.py`에서 현재 상태의 확률과 제한된 기하분포 기대 재사용 횟수를 계산할 수 있다.

### 2. 처치 후 스킬 재사용 데이터 구조화
`[적 처치 시] 이 스킬 1회 재사용` 형태를 `kill_reuse_rules`로 분리했다.
현재 단일 적 상태에서는 처치된 대상을 되살려 재사용하지 않으며, 다중 대상/대상 선택 런타임이 마련된 뒤 실제 대상에게 재사용을 연결한다. 즉 잘못된 피해를 만들지 않도록 보수적으로 처리한다.
