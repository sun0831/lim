# 림컴뎀계 0.6.15

## 인격 소속 taxonomy 확장

- 7대 키워드와 소속/계열 축을 독립적으로 유지.
- 전체 184개 인격의 raw affiliation 62종을 정규화된 56개 affiliation taxonomy로 분류.
- `affiliation_tags`를 각 인격 manifest에 추가.
- 손가락 계열: 검지/중지/약지/엄지/소지, 검계, 흑운회, 피쿼드호, 거미집 등과 회사/협회/사무소/집단을 별도 taxonomy로 관리.
- `combat_relevance=confirmed`는 현재 코드에 실제 cross-identity 전투 규칙이 구현되어 있는 경우에만 부여.
- 현재 자동 로딩되는 전투 소속 모듈은 새벽 사무소, 중지, 피쿼드호, 약지, 거미집, 흑운회.
- 그 외 소속은 `unverified`로 분류하여 자동 기믹 로딩을 하지 않음. 향후 각 소속의 스킬/패시브/크로스 인격 효과를 감사한 뒤 승격.
- 소속은 다중 태그이며 7대 키워드와 독립적임.
- 생체 재료는 기존 결정대로 `Charge` 키워드 축에 남김.
