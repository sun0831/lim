# 0.7.88 — 실제원문 상태 위력/횟수 오판 수정

## 감사 목적
기능 추가가 아니라 실제 인격/스킬 원문과 현재 계산기의 상태 위력·횟수 해석이 다른 사례를 감사했다.

## 확정 오판
기존 parser/compiler가 아래 문법을 상태 횟수(count)로 잘못 해석할 수 있었다.

- `화상 1 추가 부여`
- `화상 3 추가 부여`
- `침잠 1 추가 부여`
- `출혈 15 추가로 얻음`

실제 원문에서 이 문법은 상태 **위력(potency)** 추가이며, `상태 횟수 N 증가`처럼 `횟수`가 명시된 경우가 count다.

확인된 실제 원문 사례: 8건.

## 수정
- `skill_text_parser_v19.py`
  - `횟수 N 증가/추가/부여` → count
  - `N 부여`, `N 추가 부여`, `N 추가로 얻음` → potency
- `passive_compiler_v29.py`
  - 동일한 potency/count 분리 적용

## 검증
- 신규/관련 회귀: 57 PASS / 0 FAIL
- 전체 회귀는 이번 배치에서 별도 실행하지 않음.

## 범위
이번 수정은 상태 위력/횟수 문법의 오판만 다루며, 다른 미지원 문법을 새로 실행 가능하게 만드는 작업은 포함하지 않는다.
