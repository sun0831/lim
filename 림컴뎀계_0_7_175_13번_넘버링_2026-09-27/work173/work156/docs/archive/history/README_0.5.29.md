# 림컴뎀계 0.5.29

## 이번 버전
- 출혈 확률 계산의 턴 단위 상태 전파를 확장했습니다.
- 이제 확률 분기에서 **출혈 Count만 전달하는 것이 아니라 아군 SP / 적 SP / 특수 자원 상태도 다음 행동으로 전달**합니다.
- 동일한 상태는 합쳐서 처리하므로 전체 Clash 경로를 그대로 열거하지 않습니다.
- `sp_delta_by_outcome`을 사용하면 W/T/L 결과에 따른 SP 변화를 다음 행동의 Clash 확률에 반영할 수 있습니다.
- 스킬의 `resource_cost`, `resource_gain`, `resource_cost_max`, `resource_cost_all`도 확률 상태에서 다음 행동으로 이어집니다.
- 0.5.28의 5% 양 극단 제거 규칙은 그대로 유지합니다.
- 일반 `turn_damage` 계산은 기존 결정론적 엔진을 계속 기준으로 사용합니다.

## 상태 축
현재 확률 턴 상태의 핵심 축:
1. 출혈 Count
2. 모든 아군의 SP
3. 모든 아군의 특수 자원
4. 적 SP

따라서 앞 행동에서 자원을 소비하거나 W/T/L 결과에 따라 SP가 변하면 뒤 행동의 조건/Clash 확률 계산에 영향을 줄 수 있습니다.

## 예시
```json
{
  "sp_delta_by_outcome": {
    "W": -10,
    "L": 5
  }
}
```
- 승리 후 아군 SP -10
- 패배 후 아군 SP +5
- 이후 요청 행동은 변경된 SP를 기준으로 계산
