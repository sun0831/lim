# 림컴뎀계 0.5.9

## 변경점

0.5.8의 특수기믹 공백 분석에서 **1턴 피해량 계산과 직접 관계없는 미지원 효과를 우선순위 목록에서 제외**하도록 개선했다.

### 제외 대상 예시
- 체력 회복 / 최대 체력 관련 효과
- 보호막 및 단순 생존 유지
- 전투 BGM 등 전투 연출
- 단독 방어/생존 효과
- 기타 피해량에 직접 기여하지 않는 효과

단, 하나의 패시브에 회복과 공격력 증가, 피해량 증가, 스킬 변형, 추가 공격 등의 효과가 함께 있으면 해당 패시브는 제외하지 않는다.
