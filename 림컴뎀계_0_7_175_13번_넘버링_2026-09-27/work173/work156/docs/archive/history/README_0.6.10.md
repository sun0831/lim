# 림컴뎀계 0.6.10

0.6.10은 패시브의 **명명 자원/스택당 피해량 증가**를 실제 코인 피해 계산 경로에 연결한 패치입니다.

### 핵심
- `자신의 오혈 1 당 스킬 피해량 +3%`와 같은 명명 자원 기반 피해 증가를 공통 `ResourceField`로 계산합니다.
- `흑수환염[黑獣丸染] 1 당 피해량 +5% (최대 55%)`처럼 한글/한자 혼합 자원명도 처리합니다.
- `N당 피해량`을 단순 고정 피해 증가로 오인하지 않도록 Parser 우선순위를 수정했습니다.
- 명시적인 발동 시점이 없는 피해 증가 패시브는 `CoinStart`에서 평가하여 실제 DamageEngine의 코인 계산 컨텍스트에 적용합니다.
- 기존 ID별 특수처리는 추가하지 않았습니다.
