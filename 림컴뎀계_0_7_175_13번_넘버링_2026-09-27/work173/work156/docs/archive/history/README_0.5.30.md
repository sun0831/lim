# 림컴뎀계 0.5.30

## 이번 버전
- 확률형 출혈 턴 상태축을 **적 HP / Stagger / 방어 보정 / 물리·죄악 저항 / 상태이상**까지 확장.
- 아군 상태축도 SP, 특수 자원뿐 아니라 충전/탄환/호흡(Poise), 아군 상태이상, 죄악 자원을 함께 보존.
- 각 확률 분기에서 실제 종료 Clash 상태를 만든 뒤 후속 행동으로 전달하므로, 앞 행동의 피해로 적 HP가 0이 되거나 Stagger가 발생한 경우 다음 행동이 해당 상태를 사용한다.
- 확률 분기에서 스킬 변환을 **현재 분기 자원 상태 기준으로 행동 시작 시점에 재평가**.
- 행동당 자원 비용/획득은 한 번만 적용하고 W/T/L 결과별 SP 변화만 후속 분기에 추가 적용.
- 기존 양 극단 5% trimming, 99 Clash 상한, 결정론적 `turn_damage` 계산은 유지.

## 범위
아직 모든 게임 이벤트를 완전한 확률 상태축으로 분기하는 것은 아니다. 특히 복잡한 패시브/공격 중 추가공격/공명 등의 확률 상태 연쇄는 기존 Trigger/ActionQueue 계층을 계속 확장해야 한다.
