# 림컴뎀계 0.5.34

## 이번 버전

### 코인 단위 Trigger → 다음 코인 연결
확률형 Clash가 끝난 뒤 남은 아군 코인을 처리하는 구간을 코인별 실행으로 변경했습니다.

- 각 코인 직후 `after_coin` Trigger 판정
- Trigger의 플래그/자원/상태 변화가 같은 스킬의 다음 코인에 전달
- `queue_action`으로 발생한 추가 공격도 같은 확률 분기 안에서 실행
- 모든 변화는 해당 분기의 HP/상태/자원 상태에 반영
- 마지막 코인 뒤 `after_skill` Trigger도 실행
- 기존 Trigger depth 제한 유지

따라서 예를 들어 1코인 적중 → 충전 획득 → 2코인에서 충전 조건을 만족하는 식의 **같은 스킬 내부 연쇄**를 확률 분기에서 표현할 수 있는 기반이 추가되었습니다.

## 범위

이번 변경은 특히 확률형 Clash가 승리하여 남은 코인이 일방 공격으로 이어지는 구간의 코인 단위 상태 전파를 강화합니다. 모든 게임 내 코인 효과가 자동으로 데이터화된 것은 아니며, 구조화된 Trigger 규칙이 있는 경우에 우선 적용됩니다.
