# 림컴뎀계 0.5.83

## 변경
- 조건부 `최종 위력` 효과를 일반화.
- 자신의 호흡/화상/출혈/파열/침잠/진동 수치가 임계값 이상일 때 `최종 위력 +N` 패턴을 동적으로 평가.
- 대상 상태 1종 또는 2종의 합에 따른 조건부 최종 위력 증가를 동적으로 평가.
- 조건부 최종 위력은 코인 위력과 분리하여 처리하며, 실제 코인 판정 시점의 상태를 사용.
- 기존 0.5.82 기능 및 테스트 유지.
