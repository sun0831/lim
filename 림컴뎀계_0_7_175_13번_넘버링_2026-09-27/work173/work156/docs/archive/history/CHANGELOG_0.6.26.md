## 검계 본국검술 생존 Runtime

- `본국검술`의 "체력이 0이 되는 피해를 받았을 때, 해당 피해를 받지 않고 해당 턴 동안 체력 1 유지 (전투당 1회)" 규칙을 Runtime에 연결.
- `DamageEngine.apply_ally_damage()`를 추가하여 명시적으로 입력된 아군 피격/피해를 동일한 상태·이벤트 로그 경로에서 처리.
- 본국검술 보유자는 치명적 피해 1회를 방지하고 HP를 1로 유지.
- 사용 후 동일 턴의 두 번째 치명적 피해는 정상적으로 적용.
- 본국검술 수혜자에게도 동일한 1회 생존 효과가 적용되도록 상태 메타데이터와 Runtime을 연결.
- 기존 아군 Bleed 자해도 `apply_ally_damage()`를 경유하도록 연결하여 동일한 생존 규칙을 적용.
- 인게임 적 공격 자체를 자동 생성하지는 않으며, 명시적으로 제공된 아군 피해 이벤트/호출에 대해서만 처리한다.
