# 림컴뎀계 0.6.25

## 검계 본국검 전수 Runtime
- 검계 우두머리의 `본국검 - 세법 전수` / `본국검 - 자법 전수` 전투 시작 효과를 검계 소속 모듈로 분리.
- 대상은 검계 소속 생존 아군 중 느린 순으로 선택.
- 기본 부여량 1, 검계 참여 인원이 6명 이상이면 부여량 2.
- 최대 대상 수는 2명이며, `state.runtime.max_resonance_count`가 제공되면 그 값으로 상한을 제한.
- 기존 `AffiliationResolver`를 사용하여 소속 판정과 대상 선정을 공통화.
- 전수 부여 결과를 구조화된 event_log에 기록.
