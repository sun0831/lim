# 림컴뎀계 0.5.51

## 이번 버전

실제 184인격 / 621 기본 스킬 데이터의 스킬 효과를 전수 점검하면서, 딜 계산에 직접 영향을 주는 공통 스킬 패턴을 추가 지원했다.

### 1. 상태 위력/횟수 기반 피해량 증가
명시적으로 위력 또는 횟수를 기준으로 하는 패턴을 스킬 효과에서 계산한다.

예:
- `대상의 화상 10 당, 피해량 +10% (최대 30%)`
- `대상의 출혈 횟수 2당 피해량 +10% (최대 40%)`

모호한 `출혈당` 같은 표현은 잘못된 Count/Potency 추정을 피하기 위해 자동 해석하지 않는다.

### 2. 적 상태 임계값 기반 피해량 증가
예:
- `대상의 화상이 6 이상이면, 피해량 +50%`
- `대상의 출혈이 7 이상이면, 피해량 +20%`

스킬 실행 시점의 대상 상태를 기준으로 평가한다.

### 3. 적중 후 비례 추가 피해
예:
- `피해량의 30%만큼 추가 피해`
- `피해량의 40%만큼 추가 피해`

실제 해당 코인이 입힌 피해를 기준으로 추가 피해를 계산하고, HP/턴 피해에 반영한다.

## 보수적 파싱 원칙
상태명이 같더라도 게임에서 Count와 Potency가 다른 경우가 있으므로, `위력`, `횟수`가 명시된 경우만 자동으로 구분한다. 애매한 문장은 source_effects/unsupported로 남긴다.
