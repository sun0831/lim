# 특수 충전 / 고유 충전 분리 감사 — 2026-09-22

## 결론

현재 catalog 원문에는 하나의 공통 자원명인 `고유 충전`이 존재하지 않는다.
실제로 사용되는 표현은 `특수 충전`이라는 **범주**와, 그 범주에 속하는 개별 명명 자원이다.
따라서 `고유 충전`을 `charge`의 별칭으로 만들지 않는다.

## 확인된 축

1. `충전 횟수` → 기존 `fighter.charge`
2. `충전 위력` → 기존 `fighter.charge_potency`
3. `충전 역장` → 별도 자원. `충전 횟수`/`충전 위력`과 합치지 않음
4. `특수 충전` → 여러 개별 자원을 포괄하는 분류 표현
5. `위력 고정 특수 충전` → 특수 충전의 별도 속성. 문장에 따라 충전 횟수 합산에는 포함되지만, 명시적으로 제외하는 규칙도 존재

## 원문에서 확인한 중요한 계약

- `위력과 횟수를 함께 보유한 특수 충전은 충전 횟수로 계산됨`
- `특수 충전(위력 고정)`을 명시한 조건은 일반 `충전 위력`과 별개로 취급됨
- `위력 고정 특수 충전 제외`라는 명시적 예외가 존재함
- `각 인격마다 충전 횟수를 20 소모할 때 충전 위력 1 얻음` 같은 규칙은 `특수 충전은 적용되지 않음`이라는 예외가 함께 존재함
- `충전 역장`을 얻을 때 다른 자원으로 전환하는 원문도 존재하므로 `충전 역장` 자체를 Charge Count로 취급하면 안 됨

## 구현 방침

이번 단계에서는 실제 명명 자원을 임의로 발명하거나 기존 `charge`에 합산하지 않는다.
대신 `SpecialChargeBook`을 별도 런타임으로 추가하여 다음을 명시적으로 표현할 수 있게 했다.

- 개별 특수 충전 이름별 count
- potency 보유 여부
- fixed-power 여부
- fixed-power 포함/제외 집계
- 고정 위력 특수 충전의 Charge Potency 오염 방지

실제 전투 효과 연결은 **각 명명 특수 충전의 원문과 획득/소모 규칙을 확보한 뒤** 수행한다.
이 단계의 runtime은 기존 계산 결과를 변경하지 않는 독립 경계다.
