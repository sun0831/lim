# 0.7.85 — 실제원문 수치 스케일링 오판 추가수정

## 목적
기능 추가가 아니라, identity_catalog_v2.json 실제 원문과 현재 passive_compiler_v29.py의 계산 해석이 다른 사례를 수정.

## 수정
- 크리티컬 피해량 스케일링을 일반 `dynamic_damage_bonus`가 아닌 `crit_damage_bonus`로 보존.
  - 자신의 호흡/호흡 위력당
  - 대상의 상태 위력당
  - 대상과의 속도 차이당
  - 자신의 호흡 위력 + 대상 상태 위력 합산
  - 자신의 20 초과 호흡 위력당
- 위 크리티컬 스케일링의 최대값(cap) 보존.
- `자신의/대상의 잃은 체력 N%당 피해량 +M%`를 실제 주체별 동적 계산으로 보존.
- `대상과 자신의 잃은 체력 합 N%당`을 양쪽 HP 손실률 합산으로 보존.
- `대상의 잃은 체력의 N%만큼 피해량 증가`를 대상 HP 기준으로 보존.
- 잃은 체력 수치 스케일링이 일반 flat `피해량 +N%`로 중복 해석되지 않도록 차단.

## 검증
- 신규 감사 테스트: 6 PASS
- 관련 기존 테스트 묶음: 59 PASS
- 전체 pytest는 이번 실행에서 47% 지점까지 진행되었고 기존 실패 2건을 포함한 상태에서 120초 타임아웃으로 중단됨. 전체 통과 수치는 확정하지 않음.
