# 0.7.55 — 아군 속도 기준 Target Selector 정합화\n\n## 반영\n- Target Selector에 `fastest_ally` / `slowest_ally` canonical alias를 추가.\n- 실제 runtime의 `AllySelectorTarget(speed_max/speed_min)`과 동일한 속도 비교 의미를 standalone selector에서도 사용하도록 경계를 맞춤.\n- 대상 후보는 생존 아군만 사용하며 동률은 기존 후보 순서를 유지하는 deterministic tie-break를 유지.\n- 실제 identity_catalog_v2.json에서 `속도가 가장 빠른 아군` 48건, `속도가 가장 느린 아군` 12건의 원문을 확인.\n\n## 범위\n- 1턴 계산기에서 필요한 아군 대상 선택만 다룸.\n- 새로운 속도 규칙이나 동률 규칙을 게임 원문 없이 추측해 추가하지 않음.\n
