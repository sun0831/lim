# 림컴뎀계 0.5.33

## 이번 버전
- 확률형 Clash의 실제 피해가 발생하는 **후속 코인 구간**을 코인 단위로 추적.
- 각 코인 전후의 피해량, 적 HP/Stagger, 공격자 자원, 상태이상 상태를 `coin_trace`로 기록.
- 코인별 자원 소모가 다음 코인에 전달되는 기존 엔진 동작을 확률형 결과에도 명시적으로 보존.
- 따라서 같은 스킬의 다음 코인이 앞 코인에서 바뀐 자원/상태를 그대로 참조할 수 있는 경로를 검증.
- 기존 출혈 5% trimming, 99 Clash, HP/Stagger/SP/자원/Trigger 전파는 유지.

## 주의
확률형 Clash 자체의 W/T/L 교환 구간은 여전히 상태 집계 방식으로 계산하며, 실제 피해가 발생하는 후속 공격 코인에 대해서 코인 단위 상태 추적을 제공한다.
