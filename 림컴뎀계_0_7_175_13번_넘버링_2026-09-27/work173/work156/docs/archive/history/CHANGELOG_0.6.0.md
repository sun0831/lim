# 림컴뎀계 0.6.0

## 핵심 변경

### 1. 아군 적중 → 교차 원호공격 브리지
- `자신을 제외한 아군의 스킬이 적에게 적중하면` 계열 패시브를 별도 트리거로 컴파일.
- 소유자 자신은 자동 트리거 대상에서 제외.
- `실제 피해 > 0`인 기본 공격 적중만 발동.
- `턴 당 N회` 제한을 기존 TriggerRuntime activation scope로 적용.
- 현재 카탈로그의 **홍원 방랑무사 료슈 - 군.가.곁.좋**의 `어이, 물러서라` 연계를 대상으로 검증.

### 2. 적의 아군 공격 종료 → 원호공격 이벤트 브리지
- `적이 아군을 공격하여 해당 아군이 사망했거나 체력이 N% 미만` 계열을 보수적으로 컴파일.
- 적의 공격 자체를 임의로 생성하지 않고, 명시적으로 공급된 `after_received_attack` 이벤트만 처리.
- 사망 또는 HP 임계값 미만 조건을 OR로 평가.
- 원호공격 대상은 이벤트의 `attacker_id`를 그대로 전달.
- 현재 카탈로그의 **홍원 방랑무사 료슈 - 협객** `가척아원` 연계 문구로 검증.

### 3. TriggerRuntime 조건 확장
- `identity_id_not`
- `received_target_died_or_hp_below_pct`
- `received_target_id`
- `received_target_hp_below_pct`

## 의도적으로 하지 않은 것
- 적 행동을 자동으로 추정하거나 생성하지 않음.
- 불명확한 `피격 후` 문구를 임의의 전투 이벤트로 변환하지 않음.
- 확률/기대값 보정을 추가하지 않음.
