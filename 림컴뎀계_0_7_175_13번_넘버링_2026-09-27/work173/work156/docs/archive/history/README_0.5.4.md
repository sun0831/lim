# 림컴뎀계 0.5.4

사용자가 초기 예열 상태를 직접 지정하고, 같은 1턴 안에서 자원/조건이 충족되면 후속 스킬의 변형·특수 기믹이 발동하도록 계산하는 버전.

핵심 원칙:
- 초기 예열은 계산기가 추론하지 않음. 사용자가 자원/상태/활성화 여부를 직접 입력.
- 패시브 활성화는 `passive_activation`으로 명시적으로 ON/OFF 가능.
- 실제 데미지 상승량은 스킬/패시브의 명시된 수치와 현재 상태에서 계산.
- 앞 행동으로 자원이 충족되는 경우 `[사용 전]` 변형을 다음 행동 시작 시 재평가.
- 총 피해량, 인격별/스킬별 피해량, 상태 변화 로그를 유지.
