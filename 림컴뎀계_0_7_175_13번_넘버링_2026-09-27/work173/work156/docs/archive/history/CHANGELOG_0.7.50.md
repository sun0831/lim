# 0.7.50 — 약지 작품명 생명주기 공통화

## 반영
- `생체 재료` 누적 변환 뒤 명시된 임계값 돌파 후 `작품명` 획득을 공통 Effect로 연결.
- 임계값은 단순 현재값 `>=`가 아니라 **이번 변환으로 임계값을 새롭게 넘었는지** 판정.
- `거미집 약지 제자(10215)`의 실제 원문:
  - `생체 재료 위력이 2 이상이 되면, 작품명: 파시아 얻음`
- `턴 종료 시 자신에게 작품명이 있으면 상태를 소비하고 다른 상태를 얻음 (전투당 1회)` 형태를 공통 `turn_end_status_transform`으로 연결.
- 실제 원문인 `작품명: 파시아 → 아이언 메이든 소멸 → 구속 해제 - 창작 몰입`을 검증.
- `아이언 메이든`과 `작품명` 중 하나만 존재할 때는 변환하지 않음.

## 검증
- 관련 및 공통 회귀 테스트: **160 passed / 0 failed**

## 보류
- 원문 후속 조건인 `흐트러짐 상태면, 흐트러짐 해제 (강제 흐트러짐 제외)`는 현재 FighterState에 아군 자체의 Stagger 상태가 canonical state로 존재하지 않아 추측 구현하지 않음.
- 따라서 이번 버전은 **상태 변환 부분만** 공통화함.
