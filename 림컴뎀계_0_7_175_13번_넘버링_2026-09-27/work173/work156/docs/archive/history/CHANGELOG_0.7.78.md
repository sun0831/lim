# 0.7.78 — 실제 원문 조건 오판 수정: 대상 출혈 임계값

## 목적
구현 누락 자체가 아니라, 실제 인격 원문에 존재하는 조건이 현재 컴파일에서 `Always`로 떨어져 계산 결과가 달라지는 사례를 수정.

- identity-10109
- 패시브: 과제평가
- 원문: `적중시 대상에게 출혈이 6 이상 있으면 정신력 2 회복.`

## 수정
