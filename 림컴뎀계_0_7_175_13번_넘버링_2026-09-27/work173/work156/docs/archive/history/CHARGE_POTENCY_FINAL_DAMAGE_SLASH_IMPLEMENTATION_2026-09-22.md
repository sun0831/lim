# 충전 위력 기반 코인 최종 피해량→참격 추가 피해 구현 감사

## 근거 데이터
- `identity_catalog_v2.json` 전체 인격 스킬 원문을 전수 검색.
- 정확히 3개의 원문 조항을 확인:
  1. `identity-10116` LCE E.G.O::차원찢개 S2 연속 차원 베기
  2. `identity-10116` LCE E.G.O::차원찢개 S3 공간 절단
  3. `identity-10713` W사 4등급 정리 요원 - CCA S3 공간 절단 - CCA 오버드라이브 4코인

## 구현
- `skill_text_parser_v19.py`
  - `resource_final_damage_scale` coin-local effect 추가.
  - 자원은 `충전 위력`으로 고정하여 `충전 횟수`와 분리.
  - `(충전 위력 × 계수)%`, 최대치, `참격` 타입을 구조화.
  - 번호 없는 `[적중시] 이 코인 ...` 형태와 `N코인 [적중시] ...` 형태 모두 처리.
- `limbus_damage_engine_v29.py`
  - 직접 코인 피해가 확정된 뒤 그 값을 base로 추가 피해 계산.
  - 추가분에만 `참격` 물리 내성을 적용.
  - 원래 코인 피해의 일반 피해 계산식과 합쳐지지 않도록 별도 event log 기록.

## 전수 파싱 결과
- 원문 조항: 3
- 실제 coin effect로 변환: 6개
  - S2 2코인 → 각 코인에 적용
  - S3 3코인 → 각 코인에 적용
  - CCA S3 4코인 → 4코인에 적용
