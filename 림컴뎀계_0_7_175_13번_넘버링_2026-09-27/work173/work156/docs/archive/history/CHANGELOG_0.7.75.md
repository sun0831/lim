# 0.7.75 — 공격 종료시 대상 사망 조건 오판 수정

## 실제 원문에서 확인된 문제
`identity_catalog_v2.json`에 `[공격 종료시] 대상이 사망하면 ...` 형태의 조건부 효과가 존재한다.

기존 `passive_compiler_v29.py`는 `공격 종료시`를 `ATTACK_END`로 올바르게 인식했지만,
`대상이 사망하면`을 Condition으로 보존하지 못해 `Always()` 조건으로 컴파일했다.

따라서 대상이 생존해도 공격 종료 효과가 발동할 수 있는 해석 오판이 있었다.

## 수정
- `TargetDeadCondition` 추가
- `공격 종료 ... 대상이 사망/죽` 문구를 조건으로 컴파일
- OneTurnCore가 실제 공격 대상의 사망 여부를 `ATTACK_END` 이벤트에 명시적으로 전달
- 다중 대상 처리 후 `state.enemy` 복원으로 인해 사망 여부가 소실되는 문제도 방지

## 범위
이번 수정은 실제 원문에서 확인된 `대상 사망` 조건의 의미 보존에만 한정한다.
새로운 일반 사망 기믹을 임의로 확장하지 않는다.
