# 림컴뎀계 0.5.1

## 목적 정렬
- 자동으로 최적 덱/순서를 찾는 최적화기는 핵심 기능에서 제외.
- 사용자가 지정한 덱, 스킬, 행동 순서와 초기 예열/전투 조건을 그대로 1턴 순차 시뮬레이션.
- 총 피해량과 인격별 피해량을 함께 제공.

## 이번 수정
- 0.5.0 ZIP에서 누락됐던 `clash_core_v24.py`를 패키지에 포함.
- v29 테스트가 독립적으로 수집/실행되도록 릴리즈 테스트 구성을 정리.
- 결과에 `damage_by_identity` 추가.
- 적 최종 흐트러짐 상태를 `stagger_level/index/thresholds/staggered`로 반환.
- 코인 피해 후 Stagger 체크 이벤트에 HP 및 Stagger 전/후 값을 기록.
- 기존 순차 상태 갱신 구조 유지: 앞 행동의 HP/SP/자원/상태/흐트러짐 변화가 다음 행동에 반영됨.

## 중요한 현재 범위
- `stagger_thresholds`는 시나리오에서 직접 입력 가능.
- 다중 대상 선택, 모든 고유 자원, 자동 추가 공격 등은 아직 일반화된 완전 구현 대상이 아님.
- 자연어 패시브는 `compiled_conservative` 모드에서 지원된 규칙만 실행.
- 자동 행동순서 탐색은 목표 기능이 아님.
