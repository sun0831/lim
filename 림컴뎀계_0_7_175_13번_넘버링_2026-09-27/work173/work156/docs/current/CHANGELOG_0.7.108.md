# 0.7.108 — 호흡 + 대상 상태 기반 크리티컬 피해량 오판 수정

실제 원문 형태인 `크리티컬 피해량 +(자신의 호흡 + 대상의 화상)% (최대 50%)` 및 `(... 호흡 위력 + 대상의 파열 위력) 1당 크리티컬 피해량 +2%`를 기존 parser가 일부 인식하지 못하던 문제를 수정.

- 호흡 potency와 대상 상태 potency의 합을 하나의 스케일 값으로 처리.
- `crit_damage_bonus` 채널을 유지하여 일반 피해량 증가와 분리.
- 최대 상한을 그대로 보존.
- 명시적 `위력` 표현과 생략된 표현 모두 지원.
- 관련 신규 테스트 2건 추가.
- 관련 targeted 테스트 15 PASS.
- fast regression 957 PASS / 9 deselected.

이번 변경은 실제 실행 경로에서 원문 의미가 누락되는 MISMATCH만 수정했으며, 아직 실행 경로가 없는 크리티컬 피해량 기믹은 별도 미구현으로 유지한다.
